# Afghan Clinic Website

Responsive English/Dari clinic website starter. Includes services, about, team placeholder, contact details, and a demo appointment form.

## Publish with GitHub Pages
Repository Settings → Pages → Deploy from a branch → choose **main** and **/(root)** → Save.

## Before using with patients
- Replace placeholder phone, address, hours, team, and service details with verified information.
- The appointment form is a front-end demo only; it does not transmit or store information.
- Do not collect protected health information until a secure, compliant booking and storage service is connected.
